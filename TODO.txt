There will be two modes of operation:

Default Mode:
The transcription will be output to STDOUT
If the input is MP3 already, no FFMPEG conversion is required.
If the input is not MP3, convert to MP3 first
Output will only be set to txt.
Use a /tmp/ location for the txt file.
Transcription should skip alignment (--no_align)

Video only mode:
The second will be to output the video with subtitles
Either subtitles will be in a separate stream or they will be baked in.

---

By default, the command will perform audio transcript of the provided media. Media that
is not in MP3 format will be converted first. The transcription will be output to STDOUT.

If the --output argument is provided, and the input is a video, then an MP4 video will be
created that contains the transcription as a subtitle track. Lastly, if the --bake option 
is included, then the subtitles will be drawn on top of the video stream (hardsubs)

Usage: $0 <input> [--output <output>] [--bake] [--help]
  <input>: Required. A media file that must exist.
  --output, -o: Optional output file to store the output video. If no file name is provided, then one will be generated.
  --bake, -b: Optional. Bake-in selector flag that will cause the subtitles to be baked into the video.
  --help, -h: Display this help message."
